## Addendum to the saved open review — m94

**I would retain the major-revision recommendation, but I would withdraw three specific objections.** The current fitter can recover the baseline rate after a proportional shock before the first quiet window. The current wave solver uses the integrated weekly baseline and reproduces the independently calculated exit exposure. The widespread insufficient-signal flags reported for the previous Czech Table 8 did not recur. Other objections survive in narrower forms. This addendum is separate from the saved open answer.

### Objections that m94 resolves

**1. A shock before the first quiet window permanently biases the fitted baseline rate — resolved for the stated proportional-shock model.** The archived review’s algebra is correct. Quiet-window hazards alone can fit perfectly at \(k/(1+\theta a)\) after an earlier offset \(a\). In m94, the code uses observed survival up to the first quiet boundary to correct the seed, reconstructs offsets for each candidate parameter pair, and jointly refits \(k\) and \(\theta\). I checked a noiseless case with \(k=0.004\) per week, \(\theta=4\), an added proportional exposure of 0.05 in week 9, and a first quiet window beginning in week 22. The released fitting function returned **0.004000 and 4.000000**. The older multiwave illustration in §3.1.1 still supplies the generating rate, so that particular figure establishes less than this check or the newer validation in §S8. **9. Label each result with its reference frailty, landmark, and anchor; show observed survival from enrollment alongside it.
