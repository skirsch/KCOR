## Two remaining issues in aggregate validation

**Fractional expected counts can cause valid nested points to disappear.** This is a regression from m173 in the new nested-complement check at `code/fixed_cohort_history.py` lines 83–91. The ordinary source-history validator explicitly permits fractional expected counts for point estimation and allows floating-point tolerance. The new feasibility check rejects any nonzero death-only accounting residual. I used the existing 20-week `2023_01` fixture, changed the second birth band to 1960, constructed exact integer all-ages and 1960+ totals, retained only those two totals for both doses, and divided every risk and death count by ten. Each reported number therefore represents an exact number of tenths. The largest floating-point accounting residual in the true complement was 2.27 × 10⁻¹³ person. Both candidates accepted the individual source histories. The ordinary m173 workbook path gave all-ages KCOR 1.002719 and 1960+ KCOR 1.002371. The m177 path marked both contrasts `invalid_aggregate_counts` and withheld both points. The integer input continued to pass. The narrow fix is to retain exact checks for integer counts and use a scale-aware tolerance for fractional count differences, including inequalities at zero, consistent with the existing source-history policy. The integer-only person bootstrap is unaffected.

**Cause-specific deaths in the undisplayed young stratum can exceed all its deaths.** This is a pre-existing partial-input validation gap in `code/fixed_cohort_history.py` lines 63–74. I supplied three integer histories per dose: the displayed 1960 stratum, a wider 1960+ total, and the full total. I added 100 survivors to both totals. The displayed young stratum recorded zero COVID deaths each week. The wider young total recorded the same all-cause deaths as the displayed stratum and one COVID death. The full total also recorded one COVID death, so the full-minus-young complement remained feasible. Each displayed row individually satisfied COVID deaths ≤ all deaths. The undisplayed younger stratum consequently had one COVID death among zero all-cause deaths each week. Both versions accepted the points with status `ok`; m177 gave 1.002715 for all ages and 1.002363 for 1960+. The validator marked both wider populations unsupported for joint resampling. This example identifies a contradiction in the supplied cause breakdown. Its all-cause margins themselves are feasible. Applying the existing cause-specific feasibility condition to the supplied-minus-displayed remainder would detect the contradiction.
