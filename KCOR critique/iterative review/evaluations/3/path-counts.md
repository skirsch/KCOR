### Coding rules

- **Zero gap** requires a reported noiseless no-wave run with a recovered positive frailty variance followed by a zero applied variance at a numerically zero gap offset. General descriptions of the nonpositive-offset branch are recorded separately below.
- **Prior wave** requires the separate opening-window rate ambiguity. An unknown opening exposure `a` can make `k/(1+θa)` look like the baseline rate in a zero-offset seed. A complaint about using early weeks to fix `k` alone does not meet this criterion.
- **Raw Table 9** requires the report to connect the published week-80 values to an anchored calculation on raw hazards with no frailty fit. Discussion of survivor-hazard injection, direction or the cumulative target alone is insufficient. Matching the printed numbers demonstrates raw reproducibility. It cannot establish the historical producing run without provenance.
- **Anchor** counts an explicit objection that the anchor removes sustained level differences, or a Table 8 comparison showing what the raw anchored ratio already achieves. **Gate** separately counts an explicit challenge to retaining insufficient-signal components in Table 8. Czech α deactivation is coded separately.
- **Fixed/joint** requires a discrepancy between the ordinary default and the manuscript or publication path. **In-wave** requires a remaining exposure-attribution or survivor-moment problem. **Forced α** requires a criticism of using the unidentified or externally forced Czech exponent for the primary analysis.
- **Contamination** counts challenges to the threshold interpretation, including transferring a result from the tested grid to Czech confounding. The subset identifying a contradiction at zero contamination is reported below. **Coverage** requires a statement that historical studies have not calibrated the complete current procedure, or an explicit request to test that procedure’s interval coverage.
