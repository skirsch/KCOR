### 4. Wave correction — first-week objection resolved, moment and cumulative-scale objections remain

The code now starts the wave reference at the preceding boundary and includes the first modeled week. The archived first-week omission **is fixed**. The reference still adds \(ke^{\gamma s}\) per week, while the core uses the exact Gompertz increment \(ke^{\gamma s}(e^\gamma-1)/\gamma\). Using the same increment in both places would prevent an artificial positive excess on exact no-wave data. [Wave entry and increment](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:2668) · [Exact core increment](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:1238)

The archived numerical counterexample **still holds**. At starting variance \(\theta=1\), baseline exposure \(B=1\), and exponent \(\alpha=2\), survivors have exponential frailty with rate 2, hence \(E[Z^2\mid\mathrm{alive}]=0.5\). The code passes 0.5 as the variance of a new *mean-one* gamma and obtains a second moment of **1.5**. For a small wave the appropriate derivative on the already-inverted scale is \(E[Z^2\mid\mathrm{alive}]/E[Z\mid\mathrm{alive}]=1\) in this example. The implemented divisor is wrong even locally. The manuscript now acknowledges the approximation. The post-wave test correctly recovers a known later increment, conditional on an exit exposure supplied by that same correction. It leaves in-wave recovery untested. Fit wave exposure against the full survival law and test it against independently generated, known wave exposures.
