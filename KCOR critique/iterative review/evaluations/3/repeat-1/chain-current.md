### 1. A zero wave offset can erase correctly identified frailty

I generated 100 noiseless weekly hazards from m83’s own equation with \(k=0.001\), \(\gamma=0.085/52\), \(\theta=4\), and no wave or treatment effect. With rebased weeks 6–40 as the quiet window, the joint fitter returned **4.0000**. Adding a second equally valid quiet window at weeks 60–94 made it return **0.0000**. The seed was still exactly 4. The reconstructed gap offset was \(-2.78\times10^{-17}\). The implementation treats any first-pass offset `<= 0` as insufficient signal, resets the entire cohort’s frailty to zero, and returns `success=True`. With weeks 0–40 as the first window, I also obtained the fallback with an offset of exactly zero. [Weekly generator](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:1126), [decision and fallback](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:1474)

**Fix:** allow a gap to have zero excess while retaining the frailty estimate supported by the quiet weeks. Use a scale-aware tolerance for numerical equality. For materially negative offsets, assess the offset model and the information about \(\theta\) separately. Add this two-window example as a regression test. A tolerance fixes the roundoff example, but sampling noise around a true zero offset also needs to be handled without switching the whole adjustment on or off.

### 5. The nonlinear wave approximation also affects subsequent quiet-window fitting

M83 accurately labels the in-wave calculation an empirical approximation. It divides accumulated excess by a current-week mean-one gamma moment. The post-wave solver is exact **given the correct exit exposures**. Its regression test generates later survival from the wave exposure returned by the algorithm itself, so it verifies the conditional solver but cannot detect an incorrect exit exposure. A smaller, directly fixable inconsistency is that the wave reference still uses \(k e^{\gamma t}\) per week, while the core fitter uses the exact integrated Gompertz increment. Even a noiseless growing baseline can therefore create a small apparent positive wave excess. [Wave reference and approximation](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/documentation/preprint/paper.md:574), [implementation](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:2659), [conditional solver test](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/test/test_nph_post_window_continuity.py:34)

There is a deeper consequence. After a nonlinear wave, the survivor frailty distribution is tilted by \(\exp(-BZ-WZ^\alpha)\). In a subsequent quiet period with Gompertz baseline, the marginal hazard obeys
\[
h'=\gamma h-h^2\frac{\operatorname{Var}(Z\mid\mathrm{alive})}{E(Z\mid\mathrm{alive})^2}.
\]
With ordinary gamma depletion, that variance-to-squared-mean ratio stays at the original \(\theta\). After a nonlinear wave it generally changes. A cumulative offset alone cannot restore the original quiet-window equation. **Fix:** use the manuscript’s own survival function \(L(B,W)\) during the wave and in subsequent quiet-window fitting, or restrict frailty estimation to credible pre-wave information. Validate against independently specified wave exposures. For the Czech example, report core KCOR first and keep forced \(\alpha=1.18\) as sensitivity evidence, consistent with the finding that Czech \(\alpha\) was unidentified. [Quiet-window refit](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/documentation/preprint/paper.md:422), [survival model](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/documentation/preprint/paper.md:598), [Czech identification result](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/documentation/preprint/paper.md:923)

**What I would retain:** the exact gamma inversion, the corrected within-model identification result, and KCOR as a sensitivity analysis showing how specified frailty assumptions change a cumulative comparison. Before presenting it as a validated depletion adjustment, I would fix the zero-offset failure, rerun the positive controls and coverage with one declared estimator, and apply the stated diagnostic gate to Table 8. Those changes directly address the cases where this edition can give a reproducible number with an unsupported interpretation.
