### 4. Wave correction — first week fixed, survivor-moment objection still exact

The code now starts from the cumulative hazard **before** the first modeled wave week, adds that week’s baseline, and measures its excess. It also takes the identity branch at \(\alpha=1\). The prior first-week objection is resolved, and the implemented mean-one proxy tends to one as \(\alpha\to1\). The earlier argument for a finite jump at one does not apply to this code. [Wave entry and identity branch](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:2625) · [Wave baseline](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:2668) · [Core weekly increment](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:1241)

The archived **0.5 versus 1.5** example still holds. With \(\theta=1\) and prior baseline exposure \(B=1\), survivors have an exponential frailty distribution of rate 2. Thus \(E[Z]=0.5\) and \(E[Z^2]=0.5\). At \(\alpha=2\), the code’s mean-one gamma proxy returns **1.5**. For a small wave the correct derivative of *inverted* cumulative hazard with respect to wave exposure is \(E[Z^2]/E[Z]=1\). Dividing by 1.5 already underestimates the wave at first order. The paper now labels the operation approximate. Its tail equation is correct conditional on the exit exposures, and the tail test uses the code’s own estimated exit exposure as input. The remaining fix is to fit the full survival law through the wave and test recovery against an independently specified wave exposure.
