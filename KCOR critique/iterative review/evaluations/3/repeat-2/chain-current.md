### 1. A zero wave offset can erase well-identified frailty

On its first reconstruction pass, the fitter tests whether **any** incremental gap offset is `<= 0`. If so, it returns applied \(\theta=0\), records `success=True`, and flags insufficient signal. A gap with no excess mortality has a true offset of zero even when the quiet-window data identify substantial frailty precisely. The sign of the gap estimate answers a different scientific question from the presence of frailty. [Offset calculation and return branch](/C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:1469)

I tested the current joint fitter on exact Gompertz–gamma weekly hazards with \(k=0.003\), \(\theta=4\), \(\gamma=0.085/52\), 130 weeks, quiet weeks 0–39 and 80–129, and **no wave**. The seed recovered \(\theta=3.9999999998\). The reconstructed offset was \(-2.76\times10^{-12}\), and the fitter returned zero. Increasing the gap hazards by one part in \(10^8\) changed the returned variance back to approximately four. The endpoint consequence is substantial: using the zero fallback gives a cumulative hazard of **0.25182**, while the generating baseline is **0.43454**. In a separate check with 200 independent, one-million-person draws from that same model, 102 received the insufficient-signal flag. This example uses the edition’s own weekly equation and `joint_seed=True`. [Weekly model](/C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:1126) · [Joint seed](/C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:1375) · [Applied zero](/C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:1496)

**Fix.** Allow zero gap excess while retaining the quiet-window frailty fit. If wave offsets must be nonnegative, estimate them subject to that constraint and assess uncertainty in \(\theta\) separately. A numerical tolerance would fix the roundoff example, but sampling variation around a true zero also needs a defined treatment. Make no-wave gaps, weak waves, and several disjoint quiet windows part of the estimator’s calibration tests.

### 5. The wave extension remains an approximation with a preventable baseline error

The manuscript now acknowledges that its in-wave mean-one gamma moment approximates the survivor moment and that dividing accumulated excess by the current factor approximates wave exposure. The post-wave survival equation is valid conditional on the exit exposures. A smaller inconsistency remains even with **no wave at all**: the core model uses the exact baseline increment \(k e^{\gamma s}\operatorname{expm1}(\gamma)/\gamma\), but the wave reference adds \(k e^{\gamma s}\). For positive \(\gamma\), that reference is systematically low, so exact no-wave data can register positive excess. The difference is small at the Czech slope, but its sign matters in code that adjusts only positive excess. [Core increment](/C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:1242) · [Wave reference and approximation](/C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/documentation/preprint/paper.md:576) · [Exit-survival equation](/C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/documentation/preprint/paper.md:598)

**Fix.** Reuse the exact weekly increment in both paths. For an inferential wave module, estimate wave increments from the same joint survival law used after exit and verify that the fitted exposures reproduce observed exit survival. Until then, the inactive-module result is the appropriate primary Czech analysis.

**Publication judgment.** KCOR can serve as a descriptive sensitivity analysis under an explicit baseline and frailty model. The revised identification argument supports that use. The evidence still falls short of validating a dependable depletion adjustment: the current fitter can discard the true variance on clean data, and accepted windows can reverse the reported comparison on real data. Repairing the offset rule and showing window sensitivity on the scale readers actually interpret would change the evidentiary value of the paper more than another near-null illustration.
