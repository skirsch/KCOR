# A zero gap offset can erase positive frailty

The frozen m83 joint fitter recovered the generating frailty variance of 4 with a single quiet window in all five examples. Adding a second quiet window to the same history made the fitter return 0 in all five runs below. Every week, including the gap, came from the same shock-free Gompertz–gamma equation. With the true parameters the reconstructed and Gompertz cumulative hazards agree at every boundary, so the true gap offset is exactly zero. An offset of zero is compatible with positive frailty.

From this directory run `py -3.11 -B gap_check.py <frozen-m83-root>`. The script imports the supplied production weekly hazard, fitter and inversion. These results used Python 3.11.9, NumPy 2.4.3 and SciPy 1.17.1. The generator uses paper §2.5's weekly equation, with slope 0.085/52 per week, entry offset zero, and no sampling or death-count gate. All fits use four anchor weeks and `joint_seed=True`. The first and split fits in each row return the same fitted rate and seed. [Executable check](gap_check.py)

The production branch tests `delta_i_raw <= 0.0` before the pooled refit. All single-window fits returned `status="ok"`. Every split fit above returned `success=True`, `status="insufficient_signal"`, and the flags `insufficient_signal=True` and `delta_negative=True`. Each retained a raw θ near 4 and applied a zero offset and zero θ. The flags for insufficient deaths, bad fit, bound hit, identifiability and negative-offset clamping were all false. See frozen m83 `code/KCOR.py` lines 1373–1395 and 1469–1516.

**Numerical sensitivity.** With handoff 2's entire 0–99 window, the fit returned 3.99999999984. On its split windows, merely regrouping the generator's multiplications and divisions changed weekly hazards by at most 4.34e−19. The reported offset changed to +4.16e−17, status to `ok`, and applied θ to 3.99999999999997. A hypothetical test for offsets below −1e−14 would avoid four of the five rejections above. The shorter blind 3 seed has greater optimization error and still triggers that threshold. A threshold of −1e−10 would avoid all five first-pass rejections. These comparisons evaluate the decision on the observed offsets. Sampling uncertainty would require a separate assessment.

**Week-90 ratio.** Blind 2 compared the positive-frailty cohort with a homogeneous cohort sharing the same true baseline. Using both production fits and cumulative inversion gives **0.740234 unanchored** and **0.752054 anchored**, against a true value of 1 on both scales. The Czech default references the fourth accumulated week, rebased index 3. Its ratio was 0.984283. The homogeneous cohort's applied θ was 0.00005449 with status `ok`. Using the exactly homogeneous denominator instead gives an unanchored 0.740238. Both raw calculations reproduce the review's 0.7402. This synthetic contrast establishes a possible error under the working model. Its magnitude has no direct empirical interpretation for Table 8.

**History.** The same nonpositive first-pass test and zero-variance return appear in m17, m42 and m61 `code/KCOR.py` lines 1468–1505. Series 2 named this rule and warned that one-sided correction could create a computable ratio. Series 3 supplied the noiseless counterexample on the revised joint fitter. N3 corrected a different operation, the week boundary used to measure the offset. Its no-pulse test checked the *raw offset*, while its full-fit recovery test used positive pulses. The present result preserves that boundary correction and exposes the subsequent decision on a valid zero offset. The separate first-window ambiguity requires an offset already present at enrollment-rebased window entry. All first windows here begin at week zero with no prior offset.
