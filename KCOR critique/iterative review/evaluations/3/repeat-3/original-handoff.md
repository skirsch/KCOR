**Major revision.** KCOR’s gamma-frailty inversion is mathematically sound when the frailty variance is given. This edition also corrects several substantive problems in the previous review. The strongest remaining objection is to the estimator that supplies that variance. **On noiseless data generated exactly from the paper’s model with true variance 4, the current joint fitter recovered 4 in its first step, then returned 0 with `success=True`.** The same fallback enters the published Czech results. ### 1. A quiet gap with no wave can erase a correctly identified frailty variance

I evaluated the paper’s exact weekly equation for 100 weeks with \(k=0.001\), \(\gamma=0.085/52\), \(\theta=4\), quiet weeks 0–23 and 50–79, and no wave anywhere. The joint seed estimated \(\theta=4.0000\). At re-entry, the true cumulative offset is zero. Its computed value was within \(3\times10^{-17}\) of zero on the negative side. The code treats **any** nonpositive first-pass offset as insufficient frailty signal and returns \(\theta=0\). An offset measures the departure during a gap. A zero offset is entirely compatible with strong frailty identified inside a quiet window. This failure occurs before sampling noise, confounding, or baseline misspecification enters the problem. There is also still a difference between the manuscript estimator and the ordinary workbook. The workbook defaults to an early-week estimate of \(k\). Table 8 explicitly enables the joint seed. Even with that seed, the final fit includes the early anchor weeks as well as the specified quiet windows. And if a wave precedes the *first* quiet window, fitting that window with zero offset has a specific consequence. In the paper’s weekly equation, a constant opening offset \(a\) gives exactly the same predictions as a zero offset with scale \(k/(1+\theta a)\). That window alone cannot recover the original \(k\) under an unknown opening offset. ### 6. The post-wave equation is a genuine repair. Its input is still an approximation

The revised post-wave calculation correctly conditions survival on reaching wave exit **given the exit exposures**. The continuity test independently integrates survival for a known later baseline increase. Inside the wave, however, the implementation still evaluates a mean-one gamma moment at a propagated *scale*. Even before a nonlinear wave, ordinary gamma depletion changes the survivor mean to \(1/(1+\theta B)\). During a wave, survival weights are proportional to \(\exp(-Bz-Wz^\alpha)\), which generally changes the distribution’s shape as well. Dividing all previously accumulated excess by today’s factor does not recover the weekly wave exposures. There is also a smaller internal discrepancy: the wave reference adds \(k e^{\gamma t}\) per week, while the core fit uses the integrated Gompertz increment \(k e^{\gamma t}\operatorname{expm1}(\gamma)/\gamma\).
