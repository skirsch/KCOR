### The identification claim needs a narrower statement

For any observed cumulative hazard \(H(t)\), every candidate \(\theta>0\) gives a baseline \(B_\theta(t)=[\exp\{\theta H(t)\}-1]/\theta\) that reproduces the same survival exactly. The fixed Gompertz slope therefore does substantive identifying work. Even *within* that model, the proposition’s equivalence between nonzero curvature and positive frailty is false. With \(\theta=0\), a growing Gompertz baseline already produces curvature. With \(\theta k=\gamma>0\), baseline growth and depletion cancel exactly, giving constant observed hazard and **linear** cumulative hazard. The manuscript already acknowledges that a treatment effect resembling depletion can pass its diagnostics. That qualification should govern the abstract and conclusions too. ### The optional wave correction has a separate mathematical error

The manuscript defines the correction factor as the survivor moment \(E[Z^\alpha\mid\text{alive}]\). Under baseline exposure \(B\) alone, an initially mean-one gamma frailty has survivor mean \(1/(1+\theta B)\). The code instead passes \(\theta/(1+\theta B)\) into a **new mean-one gamma** moment. For example, at \(\theta=B=1,\ \alpha=2\), the true survivor second moment is **0.5** and the code returns **1.5**. During a wave the survivor distribution is tilted further by \(\exp(-WZ^\alpha)\). Dividing accumulated excess by a single current moment does not invert that survival law. I checked this with a noise-free calculation using the repository functions and the manuscript’s survival law. With known parameters, \(Z\) exponential with mean one, weekly baseline increments \(0.01e^{0.002t}\), and wave exposure growing by 0.005 per week for 30 weeks, the true exit exposure was **0.1500**. At the Czech setting \(\alpha=1.18\), the code recovered **0.1417**. The revised post-wave conditional-survival equation is sound *given correct exit exposures*. The error is already present at wave exit. I would use the same survival integral **during** the wave, solving for exposure conditional on an explicit baseline path, and propagate uncertainty in that path. For Czech primary results I would turn the module off. The paper declares \(\alpha\) unidentified, while the shipped Czech configuration forces **1.18** and labels it sensitivity-only.
