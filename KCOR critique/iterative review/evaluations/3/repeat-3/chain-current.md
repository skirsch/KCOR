### 4. The wave correction has a valid post-wave equation and an approximate input

The revised manuscript now states the limitation plainly. Within a wave it divides accumulated excess by a current-week proxy for the survivor frailty moment. After the wave it solves the correct conditional survival equation **given the estimated exit exposures**. An accurate post-wave solver therefore carries forward any error in the inferred wave exposure. [In-wave approximation](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/documentation/preprint/paper.md:576) · [Post-wave equation](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/documentation/preprint/paper.md:600)

For a check at the exponent actually used in Table 8, take mean-one exponential frailty, known baseline cumulative exposure \(B=1\), and true wave exposure \(W=0.25\). Numerical integration of the paper’s own \(E[\exp(-ZB-Z^{1.18}W)]\) gives survival **0.447382**. Applying its in-wave calculation with that exact survival and baseline gives **\(W=0.225312\)**. This is a model counterexample, not an estimate of the Czech error. A further, smaller inconsistency is that the wave reference still uses \(k e^{\gamma t}\) for a whole week, while the revised core uses the exact increment \(G(t+1)-G(t)\). [Moment and reference calculation](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:2659) · [Exit attribution](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/code/KCOR.py:2708)

**Fix.** Where an independently justified baseline path exists, solve \(E[\exp(-ZB(t)-Z^\alpha W(t))]=S_{\rm obs}(t)\) during the wave too. Use the same weekly baseline increments throughout. Test recovery against wave exposure specified *before* generating survival. The current continuity test takes the fitter’s own exit exposure as its input truth, so it tests the tail solver only. [Continuity test](C:/Users/jasmi/AppData/Local/Temp/kcor-s3-8d29/m83/test/test_nph_post_window_continuity.py:34)

**Scientific judgment.** KCOR is defensible as a descriptive contrast under explicit baseline and frailty assumptions. The first publication priority is to fix the zero-offset fallback and regenerate Table 8 and Table 9 with the primary fitter. The next is to measure coverage and material error among diagnostic passes for that exact revision. Until then, a flat anchored curve, an interval containing one, or a successful fit provides too little evidence that the procedure recovered the intended depletion-adjusted contrast.
