### 1. A zero gap effect can erase correctly identified frailty

I used 100 exact weekly increments with \(k=0.001\), \(\gamma=0.085/52\), \(\theta=4\), and quiet weeks 0–29 and 50–89. With no shock anywhere, the first quiet window recovered \(k=0.001\) and \(\theta=4.000000000000025\). The true offset on re-entering the second window was zero. Floating-point reconstruction gave \(-1.39\times10^{-17}\). The code tests `delta_i_raw <= 0`, returns \(\theta=0\), and sets both `success=True` and `insufficient_signal=True`. Multiplying baseline increments in gap weeks 35–44 by 1.00001 gave a final estimate of 4. Multiplying them by 0.99999 gave 0. This is a discontinuity in the estimator. A gap with no excess mortality says nothing by itself about whether the quiet weeks identify frailty. Frailty uncertainty should be assessed from the quiet-window observations themselves, for example by profiling \(k\) and \(\theta\). I would also specify one primary fitter from entry point to output. Section 2.5 prescribes a joint seed and a quiet-weeks-only final objective. The ordinary workbook defaults to a fixed-\(k\) seed, and both modes include four early anchor weeks in the final fit even when they fall outside the quiet windows. ### 4. The identification argument needs an empirical sensitivity analysis

For any observed cumulative hazard \(H(t)\), every candidate \(\theta>0\) gives a baseline \(B_\theta(t)=[\exp\{\theta H(t)\}-1]/\theta\) that reproduces the same survival. The revised equation \(\theta=(\gamma h-h')/h^2\) explains exactly what identifies frailty *within* a quiet Gompertz interval. It also shows why the assumed slope matters. At a given hazard and derivative, changing \(\gamma\) by \(\delta\gamma\) changes inferred \(\theta\) by \(\delta\gamma/h\). Cohorts with different hazard levels need not experience cancellation in their ratio. The main text says a prespecified slope sweep confirms stability. The supplement gives a fixed implementation value and an instruction to check sensitivity. ### 5. The wave correction remains approximate, and Table 8 uses it

The revised paper correctly acknowledges the in-wave approximation. The code evaluates a **mean-one** gamma moment at a propagated scale, while its identifying equation calls for \(E[Z^\alpha\mid\text{alive}]\). Even before a wave, with \(\theta=1\), cumulative baseline exposure \(B=1\), and \(\alpha=2\), the true survivor second moment is **0.5** and the code’s factor is **1.5**. A nonlinear wave further selects survivors by \(\exp(-WZ^\alpha)\). In an independent noise-free check with unit exponential frailty, \(k=0.01\), weekly \(\gamma=0.002\), \(\alpha=1.18\), and wave increments of 0.005 in weeks 10–39, the code estimated exit exposure **0.14216** against a true **0.15000**. The post-wave conditional-survival equation is sound given correct exit exposures. It inherits the in-wave error.
