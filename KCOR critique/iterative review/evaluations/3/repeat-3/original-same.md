# Scientific review of the revised KCOR edition

**Major revision.** The revised paper gives the correct gamma-frailty inversion, corrects its earlier scaling and curvature claims, and implements exact week-boundary hazards for the core fit. The changes improve what can be proved under the specified model. They do not establish that the estimator used for any particular registry comparison separates selection from other changes in mortality. The clearest remaining problem is empirical: the paper reports a Czech “normalized contrast” using a wave exponent its own diagnostics reject, with insufficient frailty signal in the original fit and every bootstrap draw for one enrollment.

1. **Apply the reporting rule to Table 8.** Box 2 says the wave module is inactive if α is unidentified and that unidentified normalized contrasts are withheld (`documentation/preprint/paper.md:94–98`). The Czech analysis concludes that α is unidentified (lines 923–929). Yet the revised empirical control uses α=1.18 (line 820), and its bootstrap explicitly requires that value (`analysis/table8/table8_bootstrap.py:44–52`). For the 2022_06 enrollment, four original subgroup fits had insufficient signal and all 999 draws had at least one such fit. The corresponding count was 307/999 draws for 2021_24 (`analysis/table8/table8_bootstrap.json`). These are counts of draws with a flagged component, not evidence that every pair in those draws failed. The code nevertheless pools all components, including identity fallbacks (`analysis/table8/table8_bootstrap.py:80–98`). A reported interval of [0.322, 1.268] for a ratio of 1.046 neither demonstrates useful null recovery nor quantifies uncertainty conditional on all component fits passing. Recompute the primary table with the module off, show subgroup- and pair-specific acceptance rates, and apply the same rule to the observed data and replicates. An independently prespecified α can be displayed as a sensitivity scenario, with its provenance. Label any numerical output from weak fits as a fallback analysis.

2. **There is still no single production estimator matching §2.5.** The joint nearest-window seed is now implemented. However, `code/KCOR.py:1133–1155` defaults to `joint_seed=False`, and the routine's regular analysis callers near lines 6545, 7008 and 7315 omit the argument. Table 8 uses a separate adapter to enable it (`analysis/table8/compare.py:8–11`, `replay.py:22`). Even with the joint seed, the final fit includes the union of quiet bins *and four early anchor bins* (`code/KCOR.py:1234–1253, 1402–1404, 1549–1559`), whereas the §2.5 objective sums only across prespecified quiet windows. The SI scan accurately discloses the extra bins. A first-pass nonpositive offset still substitutes θ=0 and reports optimizer success (`code/KCOR.py:1469–1518`). A simulation with no excess in a gap can generate this outcome through sampling noise alone even when frailty is substantial. Expose the published method through the normal entry point, specify exactly which weeks enter each step, distinguish admissible negative/zero offsets from genuinely uninformative fits, and propagate status to ratios, workbooks and intervals. Use versioned manifests to identify which algorithm generated each figure. A likelihood for weekly deaths given the evolving risk set would also weight differently sized bins appropriately.

3. **The fixed-slope identification result is sound but has limited empirical force.** The corrected equation h′=γh−θh² and distinction between individual- and cohort-hazard scaling in §2.4.4 resolve real errors. The new SI correctly says that an observationally equivalent disturbance can pass every diagnostic (`supplement.md:24–28`). For any observed cumulative H and θ≥0, the alternative baseline Bθ=expm1(θH)/θ produces exactly the same survival, with B₀=H. Fixing the baseline form and γ is therefore substantive. At fixed observed h and h′, a slope change δγ changes inferred θ by δγ/h. This is particularly consequential at low mortality. A common γ error need not cancel across differing cohort hazards and follow-up histories as §2.4.3 suggests. Publish the actual γ sensitivity results, likelihood profiles and sensitivity of the *contrast*, including an alternative baseline, rather than judging adequacy by goodness of fit alone. The new scan illustrates why: all 78 fits pass, yet changing window placement takes θ from essentially zero to 7.70 or 14.51 in the two dose-1 groups (`supplement.md:302–310`, `analysis/quiet_windows/windows.csv`). The script counts a local success status and guard check as a pass (`analysis/quiet_windows/scan.py:72–88`); stability across windows is a distinct claim. Show held-out predictions, the resulting range of KCOR, and the threshold by which variation matters.

4. **The current coverage evidence is more informative than the manuscript reports, and remains configuration-specific.** Person resampling, including resampling disjoint death-week/survivor cells and reconstructing overlapping groups for Table 8, is appropriate for that fixed-cohort design. The authors now correctly explain why the earlier deterministic, Poisson-resampled pilot does not estimate repeated-sampling coverage. Section 2.9.1 reports 189/200 and 502/600 from different, earlier designs. Separately, the provided *paired* experiment reports 194/200 coverage with the joint fit versus 160/200 with the fixed fit on the same datasets, 38 versus 4 discordant successes. Mean interval widths were 0.149 versus 0.048, and point-estimate RMSE was 0.0375 versus 0.0136 (`validation/person_bootstrap/paired.json:1–28`). The wider interval and higher RMSE matter alongside the coverage gain. The paired file names a source digest different from the supplied `code/KCOR.py`; its results need traceable configuration and code provenance. Report all three designs distinctly, then repeat the paired comparison through the release entry point for sparse, high-depletion, boundary, perturbed-baseline and multiple-window cases. Report rejection rates and coverage both unconditionally and among accepted fits. Explicitly identify which intervals use this procedure: a standard workbook path still uses an analytic post-anchor approximation (`code/KCOR.py:4451`), and the Czech person-bootstrap table includes weak fits.

5. **The claimed quiet-window contamination threshold contradicts the saved zero-contamination results.** Section 3.3.2 still states that a constant addition of 66% of baseline is the first crossing above one and draws conclusions about plausible Czech confounding. The uncontaminated comorbidity run already has mean 1.034 and 15/20 estimates above one. At 22% of baseline the mean is 0.989, and at 66% it is 1.062 with 13/20 above one. The uncontaminated dynamic series also has mean 1.063 (`test/quiet_window_contamination/out/quiet_contamination_agg.csv:2,7–10`). With 20 replicates per cell, classifying the mean as just above or below one gives no lower bound. The contamination starts at rebased week 4, and the experiment anchors at skip+4, a week later than the ordinary skip+4−1 rule (`run_contamination_test.py:209–217,251–278` in that directory; `code/KCOR.py:815`). An added hazard directly changes observed deaths as well as the inferred θ. Use common random numbers, matching anchor and fitter, paired changes from zero, Monte Carlo errors and an oracle-θ arm. Test a prespecified practically material deviation and reserve claims about Czech confounding for independently supported empirical bounds.

6. **The wave-tail change repairs a mathematical problem at wave exit while leaving the in-wave attribution unresolved.** The new solver correctly uses conditional joint survival L(B+u,W)/L(B,W) after exit, given the exit exposures and the assumed hazard zB+z^αW. The regression test independently integrates an example *given the W returned by the in-wave calculation* (`test/test_nph_post_window_continuity.py:32–56`). It cannot establish that W is correct. Section 2.7.3 now acknowledges that the in-wave factor uses a mean-one gamma with a propagated scale and divides accumulated excess by its current value. For instance, take initial mean-one exponential frailty, θ=1, α=2 and pre-wave B=0.5. Survivors have mean 2/3 and second moment 8/9. Infinitesimal true wave exposure dW raises the ordinary gamma-inverted cumulative hazard by 1.5×(8/9)dW = 4dW/3. The implemented mean-one moment at scale 2/3 is 5/3, so division recovers only 0.8 dW even at wave onset. Later survivor selection is generally nongamma. Also, the in-wave no-wave baseline uses k exp(γs) as a weekly increment, omitting the expm1(γ)/γ factor introduced in the core fit (`code/KCOR.py:1240–1248,2658–2678`). Use the same integrated baseline throughout. Given an independently justified baseline and α, solve for wave exposure week by week from S(t)=L(B(t),W(t)) and propagate that survivor distribution. Validate recovery of both exit exposure and later hazards from individual-level simulations, including a clean no-wave case. Keep the empirical approximation as a sensitivity option while its accuracy is unresolved.

7. **The examples distinguish targets more honestly now, but a flatter normalized curve is still a weak validation criterion.** The Cox example now discloses using the generating θ, and the new plotting script computes actual person-bootstrap error bars conditional on oracle θ (`paper.md:696–746`, `analysis/cox_intervals/figure_intervals.py:18–61`). It tests the inversion, not estimation of frailty. The actual unadjusted cohort hazard ratio in that experiment is 1/(1+θB(t)), even though the treatment multiplier at fixed frailty is one. Score the competing models against their respective population quantities, add a fitted-θ arm under equal information, and omit or fit the approximate shared-frailty comparator. The introductory example now discloses both its older monthly slope-removal algorithm and its selection for a near-null endpoint and reduced curvature (`paper.md:136–138`). Replace it with an outcome-independently chosen example from the release estimator. The age-shift exercise also uses anchored KCOR. If two cohorts' baseline hazards differ by any constant factor, anchoring makes their ratio identically one even with θ=0. Present observed age-standardized risks or risk differences, unanchored model contrasts, anchored contrasts and a no-adjustment benchmark on the same populations. This reveals what the inversion contributed and what the anchor removed.

I would retain KCOR as a descriptive sensitivity analysis under an explicit baseline and frailty model. The next decisive result would be a single versioned, blind, end-to-end analysis showing when the *estimated* adjustment improves recovery of a prespecified target and how often its diagnostics miss materially wrong answers. I inspected the supplied revision, diff, analysis code and saved outputs. I did not rerun the national registry analysis or the large simulation experiments.
