# 17.1 - Monte Carlo all-ages source selection

Persistent m181, parent m180. Code-only correction. The all-ages fit, reconstructed calendar support, and hazard construction select supplied `YearOfBirth=-2` histories independently for each `mc_id`. For exhaustive disjoint inputs, a missing total is reconstructed independently for each dose from that replicate's eligible component histories. For partial inputs, supplied wider totals are not combined with reconstructed incomplete component populations of another dose. The overlapping Table 8 layout preserves the original inclusive-1960 fallback per replicate. Existing ordinary source selection and the numerical fitter are unchanged.

## Verification

A test workbook contains two independent 20-week simulations and deliberately different age distributions. Replicate 1 has only its constituent age-group rows. Replicate 2 has its age-group rows plus exact supplied totals for both doses, or for only one dose. The new regression test compares each replicate's direct all-ages and ASMR rows processed alone, batched together, and shuffled, including every in-memory reported field; all are exactly equal. Actual written workbooks preserve both direct and pooled trajectories and their anchored and unanchored ratios within Excel numerical precision. The full-total mixed workbook has 20 direct all-ages rows and 20 pooled rows for each replicate. Both are flagged `ok`. The first replicate's direct endpoint is 1.571915, unchanged from its m180 standalone value; its pooled endpoint remains 1.428234. The second replicate's direct endpoint is 1.002405 and pooled endpoint 1.002413. These are individual simulated realization points; no bootstrap intervals are appropriate for this deterministic regression test.

The regression test fails on the original m180 with expected 40 rows versus observed 20; it passes in m181 for both complete and one-dose supplied totals. The partial-scope source-mask test confirms that reconstruction remains available for the component-only replicate but is not substituted for a missing supplied wider dose total in another replicate. The existing round-16 MC pooling standalone, batched, reordered and shuffled exact-equality test passes, including written-workbook verification and normalization-flag propagation.

Commands (relative to candidate): `python -B test/test_round17_mc_totals.py` and `python -B test/test_round16_mc_pooling.py`. The baseline regression was reproduced by running the m181 test script with m180's test modules first on `sys.path`; m180 itself was not modified.
