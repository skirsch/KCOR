# Blind review B — frozen m185

## Verdict

I did not find a new mathematical defect requiring redesign of the core estimator. The discrete survival transform, gamma inversion, reference-frailty scale, and anchoring are internally coherent under their stated assumptions. The important remaining defect I verified is **delivery of diagnostic qualifications in the ordinary workbook summary**: an apparently clean, finite contrast can be displayed without the model-discrepancy information which is necessary to interpret it. This does not change Table 8 or the correctly qualified diagnostic output in the main workbook.

### 1. Substantive reporting defect: ordinary summary loses model-discrepancy and assessment status

**Evidence.** The full ordinary `dose_pairs` worksheet retains `residual_screen_flag`, `residual_screen_unavailable`, `CI_residual_flagged_draws`, `CI_residual_unavailable_draws`, and `gap_assumption_status` (code/KCOR.py:9101–9104). The main run computes the residual status before attaching bootstrap summaries (8290–8350). But the standalone `KCOR_summary.xlsx` is generated by `create_summary_file` (9290, 9670–9730): the per-comparison row copies neither the residual screen fields nor the gap status. Its displayed asterisk is solely `abnormal_fit`. The ordinary console likewise displays the numerical fit marker (8556, 8850–8853), not the separate residual assessment. This is distinct from the MC log, which explicitly reports residual-screen flags and unavailable assessments.

**Reproduction, using only this candidate.** Generate 40 contiguous weeks from Monday 2023-01-02, two age strata (1940 and 1950) and doses 0 and 1, each with one million initial people. In week indexed i=0..39, use rounded deaths equal to opening risk times 0.002 (dose 0) or 0.002 × [1+0.15×(-1)^i] (dose 1), subtracting deaths from each subsequent opening risk; sex F. Specify quiet period 2023-14 through 2023-35; use default anchoring and module inactive, ordinary disjoint layout. Disable bootstrap for this small point/reporting check. Run the actual `process_workbook` writer and read both produced Excel files. Age 1940 endpoint from main worksheet:

- KCOR = 0.9894402322151022
- theta0_status_num = OK; theta0_status_den = OK
- residual_screen_flag = True; residual_screen_unavailable = False
- gap_assumption_status = not_assessed

The standalone summary instead reports KCOR 0.9894 without an asterisk, Row_Theta0_NonOK = 0; **neither** residual nor gap assessment columns exist. The console similarly displays an unqualified 0.9894. This deliberately alternates risk so discrepancy is visible to the candidate's own residual screen, not merely an objection to the model's assumptions. The omitted bootstrap counts follow directly from the summary writer's explicit field list; I did not rerun a full bootstrap.

**Why it matters.** A numerically successful fit is not equivalent to model adequacy. The manuscript explicitly separates these, makes interpretation diagnostic-first, and correctly retains exploratory residual flags without discarding draws. A summary-only user can perceive a near-null, numerically accepted contrast as unqualified even when the working model has been flagged, or a gap screen has not been assessed. In particular, successful fitting and an interval do not establish identification. The summary is a common standalone deliverable, so this is not simply a text typo or cosmetic layout defect.

**Minimal fix.** Carry the two point residual fields, both draw-count fields, and `gap_assumption_status` from the selected endpoint into each standalone summary row, and clearly distinguish exploratory discrepancy/unassessed diagnostics from numerical fit failure in the ordinary printed summary. Keep numerical KCOR, intervals, and current eligibility/fallback behavior unchanged. Do not convert an exploratory residual flag into an automatic frailty reset or discard otherwise valid draws. Confirm written summary and full workbook agree on both flagged and clear synthetic fits and an unassessed versus violated gap status; a few small paired draws or direct writer fixtures suffice to check field propagation. No empirical refit is needed for this reporting correction.

### 2. Minor consistency issues

- The ordinary path correctly derives the fit ISO calendar from `DateDied` (KCOR.py:6740–6746), but unlike the MC preparation path (4357–4366), it does not canonicalize/check the separate `ISOweekDied` label before first-value aggregation (6656). A discordant ordinary source label can therefore survive into reported output, though it does not alter the fitted calendar. Canonicalize the output from the validated date and disclose or flag contradictions consistently. This is calendar-label integrity, not a demonstrated bias in fitted results.
- The docstring of `build_kcor_rows` (4506 onward) still describes slope-removed hazards and analytic variance calculations instead of the present gamma-inversion, refitted person-bootstrap estimator. The standalone summary writer's missing-method fallback still says `analytic_count_based` (9704), despite the obsolete analytic interval no longer being the default. Remove these misleading legacy descriptions/defaults; use unavailable for an absent method.

## What I would not change

- The method is an explicitly conditional, non-causal descriptive contrast; unknown cohort-specific mean risks and observationally equivalent treatment/baseline explanations cannot be identified from these counts alone. Those are disclosed limitations rather than implementation failures.
- The shared fixed Gompertz slope and post-skip mean-one gamma assumptions supply model identification. Diagnostics cannot prove them; the paper already warns that valid-looking fits may absorb treatment effects or other baseline drift.
- Anchoring intentionally removes reference scale and cannot detect a constant normalized hazard ratio. The unanchored estimand is separately available. No replacement estimand is warranted.
- The Czech age-shift controls are not known exact null targets; Table 8 explicitly notes residual flags in essentially every draw, incomplete signed-gap screening, and interpretability for descriptive audit only. The historical window-selection and product-restriction issues, optional alpha's lack of identification, and bootstrap coverage limitations are explicitly disclosed. They constrain the strength of the evidence but do not identify a new defect in the core inversion or warrant redoing the documented design.
- Retain the empirical data, original anchors, gap constraint, residual-screen interpretation, and current fit flags while fixing the summary delivery.

Scope: reviewed manuscript and supplement, core gamma fit/inversion, nonlinear survival implementation, bootstrap and history/accounting rules, and summary/reporting paths. Ran the targeted 40-week written-workbook reproduction in a temp directory outside the candidate; no full bootstrap.
