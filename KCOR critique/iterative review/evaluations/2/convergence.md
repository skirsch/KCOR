# Convergence of the first three-path evaluation

**All nine open reviews of the revised repo recommended major revision.** Each of the three blind reviewers found the principal implementation and validation discrepancies on its own. Each continuing reviewer and each fresh handoff reviewer found them as well. The replies also distinguish corrections already made from broader questions those corrections do not settle. This is convergence of reviewers on this frozen edition. One completed revision cycle cannot establish stability across future revisions.

## Further findings and their scope

| Topic | Specific concern and evidence |
|---|---|
| Weekly boundaries | The objective still compares an integrated weekly observation to a point prediction. The gap routine stores the start-of-bin cumulative value before adding that bin's deaths. The in-wave reference also starts from the first wave bin's ending value. Each boundary issue has its own consequences and requires its own test. |
| Diagnostics and study selection | The Czech YAML comment cites observed harm in motivating window choice. It documents an outcome-informed rationale but cannot establish the full chronology. The empirical illustration script selects end ratios in 0.85–1.15 and favors reduced curvature. The window scanner computes summary pass rates after selecting passing rows, so an apparent 100% pass rate is uninformative. |
| Estimand and strata | The paper describes a single anchor week and a reference-window mean in different places. The real pipeline uses one indexed anchor. An anchored ratio measures drift and loses constant level differences. Table 8 fits the contributing strata and combines log ratios with mortality-dependent weights. A blanket statement that strata are never fitted needs reconciliation. |
| Coverage and precision | The old pilot uses an estimator evaluated on a finite reference draw as truth, and several scenario generators give deterministic fractional deaths. The later studies with independent cohorts address different questions. A positive equal-frailty or single-window result does not establish Table 8 coverage under pooling, fallback and forced wave settings. |
| Other simulation and figure provenance | The recovery study uses noiseless trajectories and an initial hazard known from the generator. The historical grid uses a different fitter. The shared-frailty comparator is described as a calibrated proxy. The Cox KCOR plotting function draws points and a line despite the caption's bootstrap bands. These qualifications attach to individual demonstrations. |
| Biological interpretation | A smooth cohort-specific baseline can reproduce the same mortality curve under different variances. Passing checks within a model does not identify the biological source. Conditioning on survival after the skip changes the population. The direction of bias from subsequent exposure changes requires assumptions about who crosses over and when. |
| External inputs | The Czech analysis used a fixed wave exponent that Table 8 explicitly discloses. Failure to identify that parameter in this dataset limits the empirical interpretation. The paper's optional identification exercise and a run conditioned on an external value are different analyses. |
