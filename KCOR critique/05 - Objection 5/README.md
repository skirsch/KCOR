# Objection 5: consistent validation target

The original item 5 in [the independent review](../KCOR_Independent_Review_EN.md) concerns comparisons that may treat a causal null, an observed mortality contrast, and KCOR's descriptive adjusted contrast as interchangeable.

Status: the [target audit](INITIAL_TARGET_AUDIT.md) confirms that the paper defines the quiet-window stress test's null as equal underlying baseline hazards. The proposed correction is to describe upward departures from this null plainly and qualify claims that compare KCOR accuracy with Cox accuracy. The [corrected objection 1 note](<../01 - Objection 1/KCOR_Objection_1_Corrected_Framing.md>) covers the different reference used in the later contamination extension.

The remaining review should focus on the Cox comparison's claims and distinguish an anchored change from a total level contrast.
