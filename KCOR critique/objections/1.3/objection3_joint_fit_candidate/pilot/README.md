# Exploratory joint-fit pilot results

This is the saved pilot for the separate exact conditional joint-fit candidate. Start with the [candidate assessment](../ASSESSMENT.md), [summary](assessment/summary.json), [paired point estimates](assessment/paired_points.json), [audit](assessment/audit.json), and [manifest](manifest.json). This candidate differs from the paper's written first-step objective and is not a validated replacement.

The [datasets.zip](datasets.zip) archive holds the generated evidence for this run. To restore the original paths for the analysis scripts, run `python -m zipfile -e datasets.zip .` from this directory. See the [archive index](../../../EVIDENCE_ARCHIVES.md).
