# Corrected production-code validation results

These are the frozen final datasets and bootstrap outputs after the separate Monte Carlo software fix. The study covers eight scenarios, including the unequal-frailty case discussed in objection 3. Start with the [module assessment](../ASSESSMENT.md), [results](assessment/RESULTS.md), [machine summary](assessment/summary.json), [audit](assessment/audit.json), and [manifest](manifest.json). This is a validation of the tested fixed-rate implementation, not interval coverage for the manuscript's stated joint fit.

The [datasets.zip](datasets.zip) archive holds the generated evidence for this run. To restore the original paths for the analysis scripts, run `python -m zipfile -e datasets.zip .` from this directory. See the [archive index](../../../EVIDENCE_ARCHIVES.md).
