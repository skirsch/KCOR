# Basic bootstrap interval check

This isolated module tested a basic bootstrap interval using the existing fitter at larger cohort sizes. Its intervals narrowed as counts grew, but coverage fell in the tested 16-million-person scenario. This is evidence about the tested implementation, not the paper's incompletely specified aggregate-block bootstrap. Read [the assessment](ASSESSMENT.md), [design](DESIGN.md), and [the main objection](../README.md).
